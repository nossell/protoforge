生成器替你挡掉的坑

以下四个错误都在开发期真实发生。前两个连内置模拟环境都没有拦截，由真实 Wireshark 执行时抓出， 这正是手写解析器最消耗时间的部分，也是生成器的核心价值。

ByteArray:get() 不存在

Wireshark 4.6 的字节访问 API 是 get_index()，get() 只存在于旧版教程里。生成器统一输出经过实测的方法名。

tree:add 不接受字符串值

给数值字段传格式化文本会直接抛异常，正确做法是先 add 再 append_text，官方教程也未写明。

数组偏移双重推进

元素字段各自推进偏移后，循环尾部又累加了一次元素长度，第二个元素直接越界读。手写循环的经典错误。

块注释多一个空格

-- [[ 会被当作单行注释，第二行中文直接变成代码，整个文件语法错误。工具生成不会犯这类错。
